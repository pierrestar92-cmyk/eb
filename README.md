# eBesucher Monitor

Android-App zum Überwachen von zwei eBesucher-Surfbars.

Geplante Funktionen:

- Status von zwei Surfbars anzeigen
- BTP/Punkte pro Surfbar anzeigen
- letzte Aktivität anzeigen
- manuelle und automatische Aktualisierung
- API-Zugang über Benutzername und API-Key
- APK-Build über GitHub Actions

Dieses Repository enthält die Android-App für den privaten Gebrauch.
